# Bestie Surprise — V2

This version follows the structure visible in the supplied Instagram screen recording:

1. Personal intro / "take the tour"
2. Photo scrapbook where the recipient can add photos
3. Broken-photo sliding puzzle
4. Sealed letter / envelope interaction
5. Tick-each-promise + handwritten-style signature
6. Final question with a genuine choice
7. Animated confirmation screen

## Customize

Edit the constants at the top of `src/main.jsx`:

```js
const ME = "Tanish";
const HER = "Bestie";
const REQUEST = "Will you be my Valentine?";
```

Replace `REQUEST` with whatever you are actually asking her.

## Run

```bash
npm install
npm run dev
```

## Build
